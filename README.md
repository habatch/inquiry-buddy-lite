# 🌱 探究伴走ノート (AI なし版)

高校生の「総合的な探究の時間」を 8 ステップ (+ 解放ステップ 2 つ) で伴走する Web ワークブック。
「探究伴走 AI」(Next.js + LLM 版) から **AI を抜いた版** で、サーバも API キーも不要。
静的サイトとして配信するので **運用費 0 円・利用回数の上限なし** で使えます。

## AI 版との違い

| | AI 版 (inquiry-buddy-web) | この版 (inquiry-buddy-lite) |
|---|---|---|
| 対話 | LLM がソクラテス式に質問 | 固定の問いカード + 「考える角度」ヒント |
| 次へ進む判定 | AI が判断 (`<NEXT_READY/>`) | 記入 (最小文字数) + 自己チェックリスト |
| ステップ 1 の話題 | LLM が生成 | 興味分野別の話題バンク (`lib/topicBank.ts`) |
| ステップ 4 の文献 | LLM が提示 | キーワード → Scholar / CiNii / J-STAGE 検索リンク |
| ステップ 8・9 | AI が添削 | A〜D 連結・字数/秒数メーター・1 分タイマー・想定質問集 |
| ランク / スコア | ○ | ○ (同じ 11 ランク・同じ解放条件) |
| Word 出力 | サーバで生成 | ブラウザ内で生成 |
| 必要なもの | Node サーバ + API キー | 静的ホスティングのみ |

スコアは「いま書かれている内容」から毎回計算するので、同じ欄を書き直しても増えません
(`lib/state.ts` の `computeScore`)。

## 行動を起こす機能

- **行動ボード** (🚀): 調べる / 聞く / 行く・見る / 試す / 作る / 発信する を自由に追加し、やる → やってる → できた で管理。「できた」+ 振り返り 10 字以上で +10 pt + 文字数ボーナス (20 件まで)
- **行動キット** (`lib/actions.ts` の `ACTION_KITS`): 文献調査・インタビュー・アンケート・研究者への質問メール・現地観察・実験・試作・発信の手順と下書き。生徒が書いた問い・仮説が `{{問い}}` などに自動で入る。外部と関わるものには「先生に相談」の注意つき
- **情報ハブ** (🔎): キーワードで辞書 / ニュース / 論文 / 統計 / 研究者 / 博物館、興味分野別の公的機関サイトを横断して開く。情報の確かさチェックつき
- 各ステップに「このステップで起こせる行動」を表示

## データの扱い

回答はすべて **その端末のブラウザ (localStorage) の中だけ** に保存され、外部には送信されません。
端末を変えるときは画面の「バックアップ保存 / 読み込み」(JSON ファイル) を使います。

## 一斉アクセス (150〜250 人) への備え

負荷試験 (2026-11-04、GitHub Pages、1 人 = 接続 1 本で HTML + CSS を取得):

| 条件 | 結果 |
|---|---|
| 改善前 (1 人 11 リクエスト) | 250 人 × 2 回目で **HTTP 429** (同一 IP、約 5 分ブロック) |
| 改善後 (1 人 2 リクエスト、125KB) | 250 人 × 3 回連続 = 750 回の表示で **エラー 0** |

学校は全員が同じ IP アドレスでアクセスするため、配信側の IP 単位のレート制限が一番の弱点。
対策として、初回表示の JS/CSS を HTML に埋め込んでいる (`scripts/inline-assets.mjs`、`npm run build` に組み込み済み)。

端末側の対策:
- 保存は 0.4 秒まとめ書き + タブを閉じる/切り替える瞬間に保存。ヘッダに保存状態を表示
- 保存できない環境 (プライベートモード等) は赤い警告 + バックアップ導線
- 複数タブで開いたときはタブ間で同期 (古いタブが上書きしない)
- 表示エラー時は記録をファイルへ救出できる画面 (`app/error.tsx`)
- Service Worker (`public/sw.js`): 2 回目以降は回線が混雑・切断しても開ける
- CPU 6 倍遅い端末 + 記録 230KB でも入力 1 文字あたり 約 50ms

**運用上の注意**
- 授業時間中は `main` に push しない (デプロイ直後の数分は配信が不安定になりうる)
- 導入前に、学校のネットワークで `*.github.io` がフィルタで遮断されていないか確認する
- 共用 PC・ログアウト時にデータが消える端末では、授業の終わりに「バックアップ保存」か Word 保存を習慣にする
- 情報ハブの Google / Google Scholar は、同じ IP から大量に検索すると確認画面 (CAPTCHA) が出ることがある。CiNii・J-STAGE・国立国会図書館サーチ・KAKEN などを併用する

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # out/ に静的サイトを書き出し
```

## 公開 (GitHub Pages)

`main` に push すると `.github/workflows/pages.yml` が `out/` をビルドして GitHub Pages にデプロイします。
リポジトリ名のサブパスで配信されるので、ビルド時に `NEXT_PUBLIC_BASE_PATH=/<repo名>` を渡しています。

## 内容を編集する

- 問い・ヒント・チェックリスト: `lib/steps.ts`
- 話題カード: `lib/topicBank.ts`
- ランク・スコア配点: `lib/ranks.ts`
